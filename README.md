# SudokoSolver

This is a small program I wrote to solve some of the sudoko's I do daily when I get stuck/

To build just do:

```
make sudoko
```

Then just run:

./sudoko "example.txt"

where example.txt is of the form below:

```
--62-4-9-
4517-----
----8----
93-------
-2-6-7-4-
-------27
----4----
-----3674
-6-9-28--
``` 

Finally to check or run any unit tests just do:

make tests
